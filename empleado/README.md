# Onboarding1.2 — prototipo de la vista del empleado

Abrir `index.html` en un navegador o servir esta carpeta como web estática.

## Alcance
- Cinco módulos correspondientes a los hitos del PDF: días 1, 3, 7, 15 y 30.
- Lección breve, ejercicio de situación, práctica supervisada, nota de dudas y avance local.
- Los casos y procedimientos son demostrativos y deben adaptarse al establecimiento.
- Los vídeos aparecen como espacio reservado. Para añadir uno, introducir la URL de un archivo autorizado en `videoUrl` del módulo dentro de `app.js`.
- La respuesta al caso y la marca de práctica no equivalen a la valoración 1–4 del responsable.

## Límite actual
Esta demo guarda datos solo en el navegador del empleado mediante localStorage. No comparte información con Onboarding1.1, no crea cuentas y no sincroniza en tiempo real. No introducir datos personales sensibles. Para un piloto compartido hará falta un sistema de usuarios, permisos y almacenamiento común.
